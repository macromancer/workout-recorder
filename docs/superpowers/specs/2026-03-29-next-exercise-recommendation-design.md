# Next Exercise Recommendation - Design Spec

## 개요

운동 기록 시 다음 운동을 자동으로 추천하는 기능. 지난 운동일의 순서 패턴을 학습하여 입력창 위에 배너로 표시하고, 탭 한 번으로 입력, 더블탭으로 즉시 저장할 수 있다.

## 추천 배너 UI

- 입력창(`#input-bar`) 바로 위에 배너 영역 추가
- 형태: `다음: 랫풀다운 60kg 12회` (운동명 + 지난번 rawText 기반)
- 1탭: 입력창에 추천 문장(rawText) 채움
- 더블탭 (300ms 이내 연속 탭): 바로 저장 (API 호출)
- 추천할 운동이 없으면 배너 숨김

## 추천 로직

### 데이터 소스

"가장 최근 운동일"의 기록을 기준 순서로 사용한다.

- `createdAt` 순서로 정렬하여 운동 순서 결정
- 같은 운동이 여러 세트면 첫 번째 등장 위치가 순서 기준
- 각 운동별 총 세트 수도 함께 파악 (완료 판단용)

### 추천 결정 흐름

1. **기준 순서 로드**: 가장 최근 운동일의 운동 순서와 세트 수 조회
2. **오늘 기록 확인**: 오늘 기록된 운동별 세트 수 조회
3. **미완료 운동 필터링**: 기준 순서의 각 운동에 대해, 오늘 세트 수 < 지난번 세트 수인 운동만 남김
4. **다음 운동 선택**: 미완료 운동 중 기준 순서가 가장 빠른 것을 추천
5. **추천 텍스트**: 해당 운동의 지난번 rawText (첫 세트 기준)

### 오늘 기록이 없는 경우

- 기준 순서의 첫 번째 운동을 추천

### 건너뛰기 처리

- 추천은 "백익스텐션"인데 사용자가 "암컬"을 기록한 경우
- 백익스텐션은 미완료 목록에 남아있으므로 다음번에 다시 추천됨
- 순서: 미완료 운동을 기준 순서대로 순회하므로, 건너뛴 운동이 우선 추천됨

### 모든 운동 완료 시

- 미완료 운동이 0개면 배너 숨김

## API 변경

### 새 엔드포인트: `GET /api/workouts/next-recommendation`

응답:
```json
{
  "recommendation": {
    "exerciseName": "랫풀다운",
    "rawText": "랫풀다운 60kg 12회",
    "setNumber": 2,
    "totalSets": 3
  }
}
```

추천할 운동이 없으면:
```json
{
  "recommendation": null
}
```

로직 (서버에서 처리):
1. 가장 최근 운동일(오늘 제외) 조회
2. 해당 날짜의 운동 순서 및 세트 수 계산
3. 오늘 기록된 운동별 세트 수 계산
4. 미완료 운동 중 순서가 가장 빠른 것 반환

## 프론트엔드 변경

### HTML
- `#input-bar` 위에 `#recommendation-banner` div 추가

### CSS
- 배너 스타일: primary 컬러 배경, 터치 가능한 크기, 기록 탭에서만 표시

### JavaScript
- `loadRecommendation()`: API 호출 → 배너 업데이트
- 1탭: `workoutInput.value = recommendation.rawText` + 파싱 미리보기 업데이트
- 더블탭: 300ms 타이머로 감지, 즉시 `saveWorkout()` 호출
- `saveWorkout()` 완료 후 `loadRecommendation()` 재호출하여 배너 갱신

## 호출 시점

- 페이지 로드 시
- `saveWorkout()` 완료 후
- 기록 탭 전환 시
